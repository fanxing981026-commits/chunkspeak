# ChunkSpeak 口语语块卡片库

这是一个可直接打开的静态网页原型，适合用来测试「英语口语语块库」这个产品方向。

## 怎么看

直接打开 `index.html` 即可体验。

## 已有功能

- 语块分类：表达观点、提出建议、社交寒暄、委婉拒绝、解释说明
- 搜索：支持中文、英文、场景关键词
- 语块详情：中文含义、使用场景、语气、练习提示
- 例句播放：使用浏览器自带英文朗读
- 收藏和已掌握：保存在当前浏览器
- 今日目标进度：适合做打卡感
- 练习区：把自己的中文想法套进当前语块
